1

Who decides? — Human judgment, AI drafting, or shared

AI can write code fast, but "AI generates, you decide" is the rule that keeps you in control. The question that sorts every task: does it need judgment about what's right, or is it mechanical drafting? Study the three cards, then drag each real moment into the right bucket. Guess freely — wrong pills carry a hover hint with the answer.

YOU

Human decides

The choices only you can make: what to build, whether the output is correct, and whether it's safe to ship. AI has no stake in your goal — you do.

+ Defines the goal & what "done" means + Judges whether the result is actually right − Slower than letting AI "just decide" − Requires you to understand the problem first
AI

AI drafts

The mechanical, repetitive typing: producing a first version of code, boilerplate, or an explanation from a clear description you give it.

+ Fast at boilerplate & first drafts + Recalls syntax you'd have to look up − Confidently wrong when the ask is vague − Has no idea if the output meets your goal
BOTH

Shared loop

Back-and-forth work: you read, test, and correct what AI produced, and it revises. Neither side owns it alone.

+ Fastest path to a working result + You stay in the loop and keep learning − Breaks down if you can't read the output − "Looks done" is not the same as "is correct"
💡 Why this matters in the AI era: AI now drafts code, explains errors, and suggests fixes — lowering the typing cost of programming. It does not decide what "correct" means for your project. Own the decisions first; let AI handle the drafting second.

3

Match the tool to its category — the landscape, not the logos

Tools come and go; categories last. Each card below describes a kind of tool, not a brand. Drag each example into the category it belongs to. Guess freely — wrong pills carry a hover hint explaining what that category is for.

EDIT

Where you write code

The editor or workspace where your files live and you type, run, and organize a project — a code editor / IDE.

+ Home base for every project − Doesn't write the code for you by itself
ASST

AI coding assistant

The thing that drafts and explains code from your plain-English description — a chat assistant or in-editor completion.

+ Turns a description into a first draft − Needs you to check whether it's correct
RUN

Where code runs

The engine or environment that actually executes your program and shows output or errors — a language runtime / browser.

+ Turns your text into real behavior − Reports errors, doesn't fix them for you
💡 Why categories over logos: the specific tool you use in year one may be gone by year three, but every workflow still has a place to write, an assistant to draft, and an environment to run. Learn the roles and any new tool slots right in.
