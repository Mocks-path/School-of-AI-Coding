Week 1 · AI Programming

Thinking Like a Programmer — the skill AI can't do for you

Four hands-on activities. Break a real goal into ordered steps, turn a vague prompt into a spec an AI can actually act on, match the four core concepts to their plain-English meanings, then read a snippet of code and predict what it does. This is the thinking underneath every program — with or without AI.

Progress
1

Match the concept — the four building blocks of almost every program

Programs look endlessly varied, but nearly all of them are built from the same four ideas. Study the plain-English cards, then drag each real-world example into the concept it demonstrates. Guess freely — wrong answers come with an explanation you can hover to read.

VAR

Variable

A named box that holds a value you can look up or change later.

  • Stores one thing under a label
  • Can be updated as the program runs
IF

Conditional

A fork in the road: if something is true, do one thing; otherwise, do another.

  • Makes a decision based on a test
  • Branches the program's behavior
LOOP

Loop

Repeat the same action many times — for each item, or until a condition is met.

  • Handles "do this to every one of them"
  • Saves you writing the step by hand N times
FUNC

Function

A named, reusable mini-program: give it inputs, it does a job and hands back a result.

  • Bundles steps under one name you can reuse
  • Takes inputs, returns an output
