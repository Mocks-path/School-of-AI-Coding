What is an AI agent?

You have been talking to language models for two weeks. An agent is what happens when you stop asking a model for an answer and start giving it a job — a goal, a set of tools, and permission to keep going on its own until the job is done. This lesson pulls an agent apart into its handful of parts, watches the loop that drives it, and draws the honest line between a chatbot, a fixed workflow, and a real agent — so the word stops being marketing and starts being something you can reason about.

01 / 04

An agent is a model with a few parts bolted on

Beginners imagine an "AI agent" as something exotic and self-aware. It isn't. It's the same language model you already know, wired to a small number of extra parts that let it act, remember, and keep going. Name the parts and the mystery disappears.

Think of a language model on its own as a brilliant advisor locked in a room with no phone, no notepad, and no door. Ask it something and it gives you a smart reply — then forgets you the moment the conversation ends. An agent hands that same advisor a goal to pursue, a set of tools to reach the outside world, a memory to keep notes, and a loop that lets it try, look at the result, and try again. Suddenly the advisor can get up, make calls, and finish a task instead of just describing one.

Take away any one part and it stops being an agent

This is the useful test. Remove the tools and you're back to a chatbot that can only talk. Remove the loop and you get a single answer, not a task carried to completion. Remove memory and it forgets what it just did and spins in circles. Remove the goal and it has nothing to aim at. An agent isn't magic — it's these few parts working together, and the whole idea collapses the moment one is missing.

02 / 04

Watch the loop that makes it an agent

The single most important part is the loop, because it's the part that separates an agent from every other use of AI. The parts feel abstract until you watch one task travel through the loop step by step — perceive, reason, act, observe, and round again.

Here is the honest core of every agent: it does not answer in one shot. It takes one small step, looks at what happened, and uses that result to decide its next step — over and over — until the goal is met or a limit stops it. Follow a simple task below: an agent asked to find and summarise three reliable articles on a topic. Notice how "reason" shows up more than once. That repeat is the loop, and the loop is the whole game.

The loop is powerful and a little dangerous

Because the agent decides its own next step, it can handle tasks you never scripted — but it can also loop far longer than you expected, call a tool you didn't want, or chase a goal you worded badly. That is exactly why the loop always ships with a leash: a cap on how many times it may run, a budget it can't exceed, and a list of tools it's allowed to touch. The loop gives an agent its power; the limits are what make that power safe to hand out. We build those limits in the next lesson.

03 / 04

Chatbot, workflow, or agent?

"Agent" gets stuck on anything with a chat box these days. It helps enormously to hold three things apart: a chatbot that answers, a workflow that follows a fixed script, and an agent that chooses its own steps. They solve different problems, and reaching for the wrong one wastes time or invites trouble.

A chatbot takes your message and hands back words — an answer, a draft, an explanation — and then it's done. A workflow is a fixed set of steps you wrote in advance ("when this happens, do that, then that"); it never improvises, which makes it wonderfully predictable and completely helpless the moment reality differs from the script. An agent sits between judgement and action: you give it a goal, and it decides the steps itself, adapting when something surprises it. The grown-up answer: reach for the simplest one that works

Newcomers tend to want an agent for everything because it's the exciting word. Experienced builders do the opposite: they use a chatbot when they only need an answer, a workflow when the steps are fixed, and an agent only when the task genuinely can't be scripted ahead of time. An agent is the most capable of the three and also the most expensive, the least predictable, and the one that needs the most supervision. Power you don't need is just risk you took on for no reason.

04 / 04

So — is this actually an agent?

You'll meet a lot of tools that call themselves "AI agents." Some genuinely are; many are chatbots or workflows wearing the label. Here's a quick, honest test. Tick the traits a system truly has, and the meter tells you how agentic it really is.

The word "agent" has become a sticker anyone can slap on a product. But the definition is refreshingly concrete: an agent has a goal, can take actions with tools, runs in a loop instead of answering once, keeps memory between steps, decides its own next move, reacts when something fails, and knows when to stop. The more of these are genuinely present, the more it deserves the name. Tick what's actually true for a system you're looking at.

The label is marketing; the traits are the truth

None of this is about snobbery over a word. It's about knowing what you're actually holding, because the three shapes behave differently and need different care. If a "productivity agent" turns out to be a chatbot, you'll wait forever for it to do anything. If a real agent is sold to you as a harmless assistant, you'll under-estimate the guardrails it needs. Check the traits, not the sticker — and once you're sure it's a real agent, the next question becomes the important one: how much freedom should it have, and where must a human stay in the loop?

What to carry forward

An AI agent is not a new kind of mind — it's the language model you already know, wrapped in a few parts: a goal to aim at, tools to act with, memory to carry notes, and a loop that lets it try, look, and try again. That loop is what turns "a smart answer" into "a task getting done," and it's exactly why an agent needs limits that a chatbot never did.

  • Agent = a model + tools + memory + a loop, all aimed at a goal
  • The loop — perceive, reason, act, observe, repeat — is what makes it an agent
  • Chatbot answers; workflow follows a script; agent chooses its own steps
  • More autonomy means less predictability — guardrails are not optional
  • If it can't act, loop, or remember, it's not an agent yet — check the traits, not the label
