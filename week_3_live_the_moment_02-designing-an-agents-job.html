Designing an Agent's Job — a good brief is a safe agent

Four hands-on activities. Assemble a clear agent brief block by block, decide which actions an agent may take on its own versus which need your sign-off, match each tool to the moment the agent should reach for it, then pin it down with a quiz on writing briefs that are safe. Most agent failures aren't the model's fault — they're a vague job description.

Safe on its own, or needs your sign-off?

The single most important design choice is what an agent may do without asking. The rule is simple: if a mistake is cheap to undo, let it act; if a mistake is hard or impossible to reverse, put a gate in front. Drag each action into the right bucket. Wrong pills hover-hint the reason.

Irreversible or high-stakes
💡 The ten-second test: before letting an agent do something on its own, ask "could I cleanly undo this in ten seconds?" Reading, drafting, and sorting pass — let the agent run. Sending, deleting, publishing, and spending fail — put a human gate in front. When in doubt, gate it.
3

Match the tool to the moment

Giving an agent tools is only half the design — it also has to know when to reach for each one (this is what "function-calling" means). A good agent calls a tool when the task needs something the model can't reliably do from memory, and answers directly when it can. Design check — which brief is safe?

Five real design decisions. Pick the safe, honest answer for each — every option comes with an explanation, and the wrong ones are the shortcuts that quietly turn a helpful agent into a risky one. Answer all five to see your score.

Quick reflect — make it stick

A sentence each is enough. Writing it in your own words is what moves it into memory. (Nothing is saved or sent.)

Pick an agent you'd actually want. Write a one-line GOAL for it, then one BOUNDARY it must never cross. What vague phrasing did you deliberately avoid?
Name one action you'd let that agent take on its own, and one you'd always gate behind your approval. What makes the difference between them?

Lesson 3 · Putting Your Agent to Work

Your brief is clear and your guardrails are set — now you run the agent for real. Next: give it a task, watch its steps, spot where it drifts or gets stuck, and tighten the brief so the next run is better. Building a good agent is a loop, just like the agent itself.
